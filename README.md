# AI Interviewer 项目
> 基于大语言模型的交互式模拟面试系统 · Kaggle 开源项目展示

## 📖 项目简介
本项目基于 Kaggle 平台完成，实现了一个由大语言模型驱动的 AI 模拟面试系统。
系统自动解析候选人简历（PDF / Word），提取求职意向岗位并匹配对应的面试风格与轮数，
由「AI 面试官」结合简历与上文逐轮追问；面试结束后由「AI 评分官」输出结构化评分报告
（总分、四维得分、优势 / 不足、改进建议、复习清单）。
完整代码、Prompt 设计、校验逻辑与运行结果见 `ai-interviewer.ipynb`。

## 📂 文件说明
- `ai-interviewer.ipynb`：Jupyter Notebook，包含简历解析、岗位提取、面试主循环、评分报告等全部代码与实验输出
- 运行前需自备一份简历文件（PDF / DOCX），notebook 中示例路径为 `/kaggle/input/datasets/ysqsww/resume/C.docx`

## ✨ 项目亮点
1. **三角色上下文隔离**：面试官、候选人、评分官各持一套 System Prompt 与独立 `messages` 历史，避免角色串味；面试官只看到自己的问答历史，评分官只看完整对话记录。
2. **双重校验抑制「AI 幻觉」**：第 2 轮起，问题必须引用候选人上一轮回答的关键词（`question_references`）；同时检测问题中是否出现简历里不存在的英文技术词（`detect_fabrication`）。任一校验不通过即自动重问，最多重试 3 次后强制引用关键词兜底。
3. **岗位驱动的自适应面试策略**：从简历中提取求职意向 → 匹配「大厂标准 / 压力型 / 温和型」三种风格（分别 5 / 5 / 3 轮，各含 6 个岗位方向）；未匹配到时交互式让用户手动选择。
4. **结构化评分与质量控制**：评分官以 JSON 模式输出报告，经 `clean_json` 清洗后解析，失败自动重试；并校验四个维度极差 ≥ 5 分，防止「全接近满分」的无效评分，最终同时打印可读报告与原始 JSON。

## 🧠 工作流程
​```
简历解析(PDF/DOCX) → 岗位提取 → 风格匹配 → 多轮面试(生成→校验→重问) → 评分报告(JSON)
​```

## 📊 输入数据说明
本项目不依赖传统表格数据集，输入为一份候选人简历文档，示例使用 Kaggle 数据集中的 `C.docx`：
- 简历全文用于构建面试官 System Prompt 与编造检测词表
- 简历前 1500 字用于提取求职意向岗位
- 示例简历为数据分析师方向，含教育背景、课程项目、技能等字段，无实习经历——用于验证「经验空白时转向基础与求职意愿提问」的规则

## 🖥️ 示例运行结果
以数据分析师（温和型，3 轮）为例，评分官输出：

| 维度 | 得分 |
|---|---|
| 技术深度 | 18 / 25 |
| 逻辑表达 | 22 / 25 |
| 项目真实性 | 16 / 25 |
| 沟通能力 | 21 / 25 |
| **总分** | **77 / 100** |

报告同时给出优势、不足、改进建议与复习清单（SQL 进阶、统计学基础、BI 工具、业务分析框架）。

## 📝 使用说明
1. 下载仓库代码
2. 安装上述依赖，并配置 `ZHIPU_API_KEY`（Kaggle 环境使用 Secrets；本地运行改为 `os.getenv` 读取环境变量）
3. 打开 `ai-interviewer.ipynb`，修改 `RESUME_PATH` 为你的简历路径
4. 逐块运行代码，在每轮「你的回答：」提示处输入回答
5. 面试结束后自动输出格式化评分报告与原始 JSON
