## ✨ 项目亮点

1. 基于 RAG 架构解析简历内容，仅围绕简历真实经历提问，不会虚构候选人项目与技能
2. 支持多轮面试对话，面试结束自动生成候选人优缺点、综合评价与录用建议

## 📊 数据集说明

> 
> 本项目使用自制文档数据，样例简历`A.docx`为人工编写的简历文档，用于简历信息抽取与面试问答实验。

## 📝 使用说明

1. 下载仓库代码
2. 配置上面列出的 Python 环境
3. 准备智谱 GLM / DeepSeek API 密钥，Kaggle 环境使用 UserSecrets 保存密钥
4. 打开`ai-interviewer.ipynb`，逐块运行代码即可复现实验

## ⚠️ 常见问题

1. sentence-transformers 导入报错：包版本冲突，重装依赖后重启内核
2. 文件读取异常：使用`os.listdir()`核对数据集真实路径
3. API 401 鉴权失败：检查 API 密钥是否有效
